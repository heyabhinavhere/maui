Support.

Open an issue on Maui’s GitHub. In Maui, Settings → General → Copy diagnostics puts the version and the last half hour of Maui's own log on your clipboard — no file names, tokens or private content are in it — so you can paste it into the issue.

Requirements

macOS 26 or later, on Apple silicon. A MacBook with a notch is Maui's home; other displays get a small shape at the top of the screen.

Uninstall

Do these in order, while Maui is still open — the first steps use its own controls.

  1. If you turned on Show Claude's usage limits: Maui → Apps → Claude Code → … → turn it off. It takes out only Maui's own status line from Claude Code. (No … menu there? Remove the statusLine entry that runs maui-hook from ~/.claude/settings.json by hand.) Maui kept a copy of that file as it first found it, ~/.claude/settings.json.before-island; delete it once you don't need it.
  2. If you connected Claude Code: Apps → Claude Code → … → Disconnect Claude Code…. Or in a terminal: claude plugin uninstall maui@maui, then claude plugin marketplace remove maui.
  3. If you connected Codex: Apps → Codex → … → Remove Maui's hook… It takes Maui's one entry out of ~/.codex/hooks.json.
  4. If you connected GitHub: Apps → GitHub → Disconnect GitHub, which also asks GitHub to end Maui's access. To be sure it ended, or if Maui is already gone, revoke it in GitHub → Settings → Applications.
  5. Settings → General → turn off Launch Maui at login.
  6. Quit Maui from its menu-bar item and move it to the Trash.
  7. Its own files, if you want them gone too: ~/Library/Application Support/Island (the Tray's copies, screenshot records, the agent helper), its preferences ~/Library/Preferences/com.abhinavjain.Island.plist, and ~/Library/Caches/com.abhinavjain.Island and ~/Library/HTTPStorages/com.abhinavjain.Island (update checks). ("Island" was Maui's name while it was made; existing installs keep these names so nothing is lost on update.) Your screenshots and original files are never inside these folders.
  8. Keychain Access: the items named com.abhinavjain.Island.github (your GitHub session) and com.abhinavjain.Island.reach (this Mac's Reach identity and the Macs it is paired with).
