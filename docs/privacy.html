Privacy.

Maui has no account, no analytics and no telemetry, and no server of ours keeps anything about you. What follows is everything that does leave your Mac, and when.

What stays on your Mac

  • Screenshots: Maui keeps a reference to each file, never a copy, and reads their text, links and barcodes with macOS's own on-device Vision. That text stays with the screenshot's card on this Mac until the card is cleared; it is never logged or sent.
  • The Tray: copies of what you keep, in Maui's own folder. Your originals are only read.
  • Converting files uses macOS's own frameworks on this Mac — no cloud conversion.
  • Coding agents run on your Mac; Maui talks to them only through a private local socket, never a network port.
  • A screenshot or file you attach to an agent's question is copied into Maui's own folder. Maui looks in that folder every hour while it is open, each time it starts and each time you attach another file, and deletes any copy that is a day old. When the agent's session has a temporary folder of its own on this Mac, the file is copied there too, so the agent can read it without asking. Maui does not delete that copy: it stays until the agent's session or macOS clears that folder. What the agent then does with it is the agent's, as with anything you give it — Claude Code and Codex may send what they read to their own services.
  • The usage vials, and Claude Code's and Codex's pages in Apps, read those agents' own records on this Mac — how much of their limits is left, and each session's name and what it is doing now. Nothing about them is sent anywhere.
  • When a Claude Code session starts, Maui's plugin tells Maui which app or terminal it runs in, so the session's line can take you there. Maui keeps that on this Mac and drops places more than two days old.

What uses the network — only when you use it

FeatureWhat is sent, to whom
GitHub, if you connect itRequests to GitHub's API, as you. Signing in, refreshing the session and disconnecting go through a small exchange service of ours on Cloudflare that holds the app's client secret, keeps nothing, and logs no tokens. Your session is stored in your Keychain, and a copy of your pull requests' titles and states is kept on this Mac so Maui opens quickly. So that it can approve and merge for you, Maui's GitHub app asks to change pull requests and the code of the repositories you choose: GitHub counts a merge as a change to a repository's code. Maui uses that access only when you press Approve or Merge.
Reach, if you turn it onMaui looks for your other Macs nearby once you choose Look for my other Macs, and keeps looking while it runs once a Mac is paired. While it looks, it announces this Mac's name (macOS usually puts your first name in it), its Reach id and its public key to devices nearby. Anything that connects is told this Mac's model and icon. When a Mac asks to pair, this Mac's wallpaper is shown to it as soon as the request appears, before the pairing is proven. After pairing, what you send goes only to the Mac you chose, over a session encrypted with keys tied to that pairing.
UpdatesWhen Maui first opens and then about once a day, it asks its update feed on GitHub whether a newer version exists. The request carries Maui's and its updater's names and versions; like any request, it shows GitHub your IP address. When there is an update, Maui shows its notes from this site and downloads it from GitHub. You can turn checking off in Settings → General.
Meetings, if you turn them onMaui reads your calendars on this Mac through macOS. Joining a meeting opens its link in your browser or meeting app.

What Reach does not protect against

Pairing shows the same six digits on both Macs. The digits are fixed for a pair of Macs, so comparing them does not stop someone who is nearby while you pair from placing themselves in the middle. Pair where you trust who is around, and unpair a Mac you no longer recognise (Settings → Reach).

Permissions

Maui asks for each macOS permission at the moment you use what needs it: your screenshot folder, Calendar, Local Network. It never asks for Screen Recording, your camera or your microphone.
