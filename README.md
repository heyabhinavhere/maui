# Maui

A small friend for the notch of your Mac. It keeps your screenshots, holds the files you drop on it, and brings your coding agents' questions to you.

**Maui 1.0 is out.** Download it from its site: https://heyabhinavhere.github.io/maui/

This repository holds what Maui publishes: its site (in `docs/`), its downloads (in Releases), its Homebrew cask (in `Casks/`) and its Claude Code plugin (in `claude-code/`). Maui's own code isn't published here.

Questions or problems: [open an issue](https://github.com/heyabhinavhere/maui/issues).

Made by Abhinav.
