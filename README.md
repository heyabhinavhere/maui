# Maui

A small friend for the notch of your Mac. It keeps your screenshots, holds the files you drop on it, and brings your coding agents' questions to you.

**Maui isn't out yet.** Its site: https://heyabhinavhere.github.io/maui/

This repository holds what Maui publishes: its site (in `docs/`) and, from the first release, its downloads, its Homebrew cask and its Claude Code plugin. Maui's own code isn't published here.

Questions or problems: [open an issue](https://github.com/heyabhinavhere/maui/issues).

Made by Abhinav.
